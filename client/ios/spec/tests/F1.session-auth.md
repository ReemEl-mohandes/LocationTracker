# F1 — Session & Authentication (characterization)

Captures current behavior of `SessionStore` + `APIClient` (auth) + `TokenStore` + `LoginView`.
Services touched: **S3 AuthAPI**, **S4 TokenStoring**. All mocked.

## Controller / coordination (SessionStore)

### F1.1 Restore with a working token — happy
- **Given** `TokenStoring.load()` returns tokens **and** `AuthAPI.me()` resolves to a profile
- **When** `restore()` runs
- **Then** state becomes `signedIn(profile)`; `onSignedIn(profile)` is called once.

### F1.2 Restore with no token — edge
- **Given** `TokenStoring.load()` returns `nil`
- **When** `restore()` runs
- **Then** `AuthAPI.me()` is **not** called; state becomes `signedOut`.

### F1.3 Restore, token rejected — error
- **Given** tokens present but `AuthAPI.me()` throws `unauthorized`
- **When** `restore()` runs
- **Then** session ends (`endSession(explicit:false)`): tokens cleared, cached profile cleared,
  state `signedOut`, `onSignedOut(false)` called.

### F1.4 Restore while offline — edge (deliberate)
- **Given** tokens present, `AuthAPI.me()` throws a non-auth network error, and a cached profile
  exists
- **When** `restore()` runs
- **Then** state becomes `signedIn(cachedProfile)`; `onSignedIn(cachedProfile)` called; tokens are
  **kept**. (Offline launch must not sign the user out.)
- **And Given** no cached profile → state becomes `signedOut`.

### F1.5 Login success — happy
- **When** `login(email,password)` and `AuthAPI.login` resolves
- **Then** state `signedIn(profile)`; `onSignedIn` called.

### F1.6 Explicit logout — happy
- **When** `logout()`
- **Then** `AuthAPI.logout()` attempted (best-effort), tokens cleared, `onSignedOut(true)` called,
  state `signedOut`.

### F1.7 Server-side expiry mid-session — error
- **Given** signed in
- **When** `.sessionExpired` notification is posted (by APIClient after a failed refresh)
- **Then** `endSession(explicit:false)`; `onSignedOut(false)`; state `signedOut`.

## Service (APIClient auth transport)

### F1.8 Cookies lifted into the store — happy
- **Given** `AuthAPI.login` HTTP response carries `Set-Cookie: access_token/refresh_token/csrf_token`
- **When** login succeeds
- **Then** `TokenStoring.save` is called with all three values parsed from the cookies.

### F1.9 401 triggers single-flight refresh then one retry — edge
- **Given** two concurrent authorized calls both get `401`
- **When** they run
- **Then** `refresh` is invoked **once** (single-flight), both retry once; a second `401` on retry
  throws `unauthorized` and posts `.sessionExpired`.

### F1.10 Missing cookies on a 2xx — error
- **Given** login returns 2xx but no `Set-Cookie`
- **Then** `missingSessionCookies` is thrown; no partial token save.

## View (LoginView)

### F1.11 URL normalization — edge
- **Given** the field is `  https://host/  `
- **When** submit
- **Then** the stored/used server URL is `https://host` (trimmed, trailing slash removed).

### F1.12 Pinning failure copy — error
- **Given** the connection fails the pin check and `APIClient.rejectedFingerprint` is set
- **Then** the error text includes that fingerprint and the hint to add it to `AppConfig`.
