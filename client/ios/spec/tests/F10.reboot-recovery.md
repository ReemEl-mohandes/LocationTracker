# F10 — Reboot / First-Unlock Recovery (characterization)

The hardest behavior. `TokenStore.isUnlockedSinceBoot`, `TrackerState`, `UploadQueue` locked-file
handling, and the `protectedDataDidBecomeAvailable` wiring. Services: **S4 TokenStoring**,
**S5 PointStore/TrackerStateStore**, **S6 KeyValueStore**, **S1 LocationProviding**.

## Service (unlock probe)

### F10.1 Locked after boot — edge
- **Given** the Keychain probe returns `interactionNotAllowed`
- **Then** `isUnlockedSinceBoot() == false`.

### F10.2 First run creates the probe — edge
- **Given** probe `itemNotFound`
- **Then** the probe item is created and `true` returned.

### F10.3 Normal unlocked — happy
- **Given** probe success → `true`.

## Model / rules (TrackerState)

### F10.4 State unreadable while locked — edge
- **Given** `isUnlockedSinceBoot() == false`
- **When** `TrackerState.load()`
- **Then** returns `nil`.

### F10.5 Migration from UserDefaults — edge
- **Given** unlocked, no state file, legacy keys `wantsTracking=true`/`trackingPausedByUser=false`
  in **S6**
- **When** `load()`
- **Then** returns `{wantsTracking:true, pausedByUser:false}` and **saves** it to the file.

### F10.6 wantsTracking fallback while locked — edge (deliberate)
- **Given** `state == nil` (locked), `authorization == authorizedAlways`
- **Then** `wantsTracking` reads `true` (start on the safe guess).
- **And Given** authorization is only When-In-Use → reads `false`.

### F10.7 updateState is dropped while locked — edge
- **Given** `state == nil`
- **When** a setter runs (`wantsTracking = …`)
- **Then** nothing is persisted (guard `state != nil`); the value at unlock is authoritative.

## Controller (reconciliation on unlock)

### F10.8 Tracker adopts real state, was-on stays on — happy
- **Given** started on the Always guess, then unlock reveals `wantsTracking == true`
- **When** `reloadAfterUnlock()`
- **Then** `resumeIfNeeded()` (keeps running).

### F10.9 Tracker corrects a wrong guess — edge
- **Given** started on the guess, unlock reveals `wantsTracking == false` while `isTracking`
- **When** `reloadAfterUnlock()`
- **Then** `stop(flushRemaining:false)`.

### F10.10 Queue does not clobber the locked file — edge (critical)
- **Given** at init `PointStore.load()` returned `nil` (present but locked) → `diskLoaded == false`
- **When** points are enqueued before unlock
- **Then** `persist()` is a **no-op**; the on-disk backlog is preserved.

### F10.11 Queue merges on unlock — happy
- **Given** `diskLoaded == false`, in-memory points M, on-disk backlog D (now readable)
- **When** `reloadAfterUnlock()`
- **Then** `pending = sortByTime(D + M)` deduped by `LocationPoint` equality; `diskLoaded = true`;
  `activeTripId` restored from **S6**; persisted; then `flush()`.
