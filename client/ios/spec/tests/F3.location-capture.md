# F3 — Location Capture & Validation (characterization)

The `CLLocation` → `LocationPoint` conversion and enqueue path. Services: **S1** (fixes in),
**S5 PointStore** (via queue). The conversion is pure and should become a **Model** function.

## Model / rules (point conversion)

### F3.1 Valid fix — happy
- **Given** a fix: acc 8 m, speed 12 m/s, course 90°, timestamp T
- **When** converted
- **Then** `LocationPoint(lat,lon, accuracyMeters:8, speed:12, heading:90, recordedAtUtc:T)`.

### F3.2 Accuracy out of range — edge/error
- **Given** `horizontalAccuracy < 0` → **Then** conversion returns `nil` (dropped).
- **Given** `horizontalAccuracy > maxAcceptedAccuracyMeters (150)` → **Then** `nil` (dropped).
- **Given** `horizontalAccuracy == 150` → **Then** accepted (boundary inclusive).

### F3.3 Unknown speed/course — edge
- **Given** `speed == -1` → **Then** `speed == nil`.
- **Given** `speed == 1500` (>1000) → **Then** `speed == nil`.
- **Given** `course == -1` → **Then** `heading == nil`.
- **Given** `course == 360` → **Then** `heading == 360` (boundary inclusive).

## Controller (handle)

### F3.4 Accepted fix is enqueued and state updated — happy
- **Given** a valid fix
- **When** `handle([fix])`
- **Then** `queue.enqueue(point)` called with the converted point; `lastLocation`/`lastPointAt`
  updated; `placeWakeFence` considered.

### F3.5 Dropped fix does not enqueue — edge
- **Given** an over-accuracy fix
- **When** `handle([fix])`
- **Then** `queue.enqueue` is **not** called; `lastLocation` unchanged for that fix.
  // TODO: bug? — a dropped fix still runs `placeWakeFenceIfNeeded(at: location)` using the raw
  (rejected) location. Record as-is; confirm before Phase 4.

### F3.6 Batch of fixes — edge
- **Given** three fixes, middle one over-accuracy
- **When** `handle([a,b,c])`
- **Then** two points enqueued (a, c), in order.
