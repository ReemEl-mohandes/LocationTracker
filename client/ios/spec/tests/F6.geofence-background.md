# F6 — Wake Geofence & Background Relaunch (characterization)

`placeWakeFenceIfNeeded`, `wakeFenceExited`, `removeWakeFence`, and the relaunch entry path.
Services: **S1 LocationProviding** (place/remove fence, start monitors).

## Model / rules (fence placement)

### F6.1 First fence placement — happy
- **Given** tracking, `wakeFenceCenter == nil`, a fix at C
- **When** `placeWakeFenceIfNeeded(at:C)`
- **Then** `LocationProviding.placeWakeFence(center:C, radius:150, id:"wake-fence")`;
  `wakeFenceCenter = C`.

### F6.2 Small movement does not churn the fence — edge
- **Given** `wakeFenceCenter == C`, a fix D with `dist(C,D) < 150*0.66 (=99 m)`
- **When** `placeWakeFenceIfNeeded(at:D)`
- **Then** no `placeWakeFence` call; centre unchanged.

### F6.3 Movement past 2/3 radius re-centres — happy
- **Given** `dist(C,D) >= 99 m`
- **Then** `placeWakeFence(center:D,...)`; `wakeFenceCenter = D`.

### F6.4 Not tracking — edge
- **Given** `isTracking == false`
- **When** `placeWakeFenceIfNeeded(at:C)`
- **Then** no-op.

## Controller (relaunch behavior)

### F6.5 Fence exit resumes tracking — happy
- **Given** `didExitRegion(id:"wake-fence")`
- **When** delivered
- **Then** `lastMovementAt` refreshed; `resumeIfNeeded()`; if tracking and stationary,
  `applyMode(full)`.

### F6.6 Foreign region ignored — edge
- **Given** `didExitRegion(id:"something-else")`
- **Then** ignored (guarded by id).

### F6.7 Visit wakes and resumes — edge
- **Given** `didVisit()`
- **Then** `resumeIfNeeded()`.

### F6.8 stop removes the fence — happy
- **When** `stop()`
- **Then** `removeWakeFence()` → `LocationProviding.removeWakeFence("wake-fence")`;
  `wakeFenceCenter = nil`.

## Service seam note

The concrete uses **classic region monitoring** (`CLLocationManager.startMonitoring(for:)`), not
`CLMonitor`, because `CLMonitor` crashed at launch on device. The `LocationProviding` interface
hides that choice; tests assert the interface calls, not the CoreLocation API.
