# F5 — Power Saving & Heartbeat (characterization)

`tick()` timing logic. Services: **S10 Clock/PowerState** (in), **S1 LocationProviding**
(applyMode / requestSingleFix out). The timing decisions are pure given an injected clock and
should become **Model**; the effects are **Service** calls.

Assumes an injected `Clock` (S10) so time can be advanced without waiting.

## Model / rules (tick decisions)

### F5.1 Switch to saving after stationary timeout — happy
- **Given** not stationary, `motionState != stationary`, `now - lastMovementAt >= stationaryAfter
  (180 s)`
- **When** `tick()`
- **Then** `applyMode(stationary:true)`.

### F5.2 Motion-confirmed still switches sooner — edge
- **Given** `motionState == .stationary`, `now - lastMovementAt >= stationaryAfterMotionStill
  (60 s)` but `< 180 s`
- **When** `tick()`
- **Then** `applyMode(stationary:true)` (the 60 s threshold applies when the chip agrees).

### F5.3 Moving chip keeps full mode — edge
- **Given** `motionState.isMoving`
- **When** `tick()`
- **Then** `lastMovementAt` is refreshed to now, so the stationary switch never triggers (a traffic
  jam / train stays "moving").

### F5.4 Heartbeat request — happy
- **Given** `heartbeatRequestedAt == nil`, `now - lastPointAt >= heartbeatInterval (120 s)`
- **When** `tick()`
- **Then** `heartbeatRequestedAt = now`; `LocationProviding.requestSingleFix()` (distance filter
  dropped).

### F5.5 Heartbeat times out with no fix — error/edge
- **Given** `heartbeatRequestedAt` set, `now - heartbeatRequestedAt >= 60 s`, no fix arrived
- **When** `tick()`
- **Then** `heartbeatRequestedAt = nil`; `applyMode(stationary: isStationary)` (filter restored).

### F5.6 Flush cadence — happy
- **Given** `now - lastFlushAttempt >= uploadInterval` (30 s normal / 60 s low power)
- **When** `tick()`
- **Then** a queue flush is requested; `lastFlushAttempt` updated.

### F5.7 uploadInterval by power — edge
- `PowerState.isLowPower()==false` → 30 s; `true` → 60 s.

## Controller side effect

### F5.8 tick re-arms the watchdog — happy
- Every `tick()` calls `TrackingWatchdog.arm()` (**S8**). See F9.
