# F2 — Tracking Lifecycle (characterization)

`LocationTracker` start/stop/auto/pause/resume + the app wiring. Services: **S1 LocationProviding**,
**S8 Notifying**, **S10 Clock/PowerState**, **S4/S5** for intent (via `TrackerState`).

## Controller / coordination

### F2.1 autoStart for a fresh signed-in user — happy
- **Given** `pausedByUser == false`, not tracking, authorization not denied
- **When** `autoStart()`
- **Then** `start()` runs.

### F2.2 autoStart is suppressed after an explicit pause — edge
- **Given** `pausedByUser == true`
- **When** `autoStart()`
- **Then** nothing happens (no `start`). This is the one thing that keeps auto-start off.

### F2.3 start when authorization is undetermined — edge
- **When** `start()` with `authorization == notDetermined`
- **Then** `LocationProviding.requestWhenInUse()` is called; updates do **not** begin yet;
  `Notifying.requestPermission()` is called.

### F2.4 start when denied — error
- **When** `start()` with `authorization == denied`
- **Then** `lastError` is set to the "off in Settings" message; no updates begin.

### F2.5 beginUpdates turns on the full stack — happy
- **Given** authorized and intent on
- **When** `beginUpdates()` runs
- **Then**, in order: a background session starts, `applyMode(full)`,
  `LocationProviding.startUpdating()` (which starts standard + significant-change + visits),
  motion starts, watchdog armed, `Notifying` "tracking on" posted, tick timer scheduled; and if
  only When-In-Use, `requestAlways()` is called.
- **And** `isTracking == true`.

### F2.6 pauseByUser — happy
- **When** the status toggle goes OFF → `pauseByUser()`
- **Then** `pausedByUser` persisted `true`; `stop()` runs; `Notifying` "tracking off (you turned
  it off)" posted.

### F2.7 stop tears everything down — happy
- **When** `stop(flushRemaining:true)`
- **Then** stopUpdating, motion stop, geofence removed, background session invalidated, tick timer
  invalidated, watchdog disarmed, `isTracking == false`, and a final `queue.flush()` is requested.
- **Edge** `stop(flushRemaining:false)` (sign-out): identical **except** no final flush.

### F2.8 resumeIfNeeded on relaunch — happy
- **Given** intent on, not tracking, authorized
- **When** `resumeIfNeeded()`
- **Then** `beginUpdates()` runs (this is the headless relaunch path).
- **Edge** intent off → nothing.

### F2.9 authorization revoked while tracking — error
- **Given** tracking
- **When** delegate reports `denied`
- **Then** `stop(flushRemaining:false)`, `Notifying` "location access turned off" posted,
  `wantsTracking` set false, `lastError` set.

## View (TrackingView)

### F2.10 toggle reflects `isTracking` — happy
- The toggle's `get` returns `isTracking`; `set(true)`→`start()`, `set(false)`→`pauseByUser()`.

### F2.11 onAppear — happy
- `TrackingView.onAppear` calls `autoStart()`.
